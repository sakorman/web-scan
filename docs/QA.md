# 本地验证记录

环境：Apple Silicon / macOS，Python 3.12.14，PyCOLMAP 3.13.0，PyTorch 2.14.1，Node.js 24.20.0。素材包括原创合成场景与 ETH3D 官方真实办公室照片，没有上传用户照片到外部服务。

## 已验证

- 自动测试：上传去重、冻结后拒绝写入、坏图片、最少帧数、并发重复任务、取消、提前访问产物、资源上限、Host / Origin、重启后数据保留。
- 渲染数值：前后 alpha 合成、梯度有限、相机背后高斯不渲染、归一化不改变投影、导出二进制布局。
- 前端 TypeScript 检查与生产构建。
- 浏览器：创建采集、校准示例、照片批量导入、训练设置、开始训练、取消、成功状态、模型加载、日志、桌面与 390 像素小屏布局。
- 原创校准环形场景：10 个已知相机视图，192 个高斯，120 步训练，约 4.66 秒；首训练视角 MSE 从 0.00339 降到 0.0000547。
- 原创纹理立方体图片：12 张未向求解器提供相机参数的照片，COLMAP 成功注册 12/12，得到约 2900 个稀疏点；经 API 上传、重建、下载的完整流程通过。384 个高斯、120 步，约 7.87 秒；首训练视角 MSE 从 0.0945 降到 0.0104。

上述秒数为单次本地小规模运行，包含对应任务的求解 / 训练 / 导出，排除人工采集与上传等待，不能推广为真实场景性能承诺。报告中的 `calibrated_fixture` 仅说明是否使用内置校准路径；普通上传照片本身也可能来自合成数据。

## 真实室内数据验证

ETH3D office：26 张真实多视角照片，未使用数据集提供的相机标定。COLMAP 注册 26/26；Brush 0.3.0 在 Apple GPU 上执行 3000 步、512 像素训练，输出 9170 个高斯，任务耗时约 40.28 秒，其中 GPU 训练日志为 25 秒。上游评估日志记录 PSNR 20.2839、SSIM 0.8577；评估图像参与过 SfM，因此不是完全独立的端到端留出测试。

6000 步复测：26/26 注册、22 张训练 / 4 张评估，生成 50223 个高斯；总任务 73.47 秒，PSNR 21.8437、SSIM 0.8919。网页内已实际检查办公室画面、拖动视角和初始相机位置。
