# 相对图像细节诊断

2026-10-29。本轮不改变相机求解、照片筛选或 Brush 训练；只在已经定位成功的照片之间标出相对缺少可见细节的视角，帮助在模型出现发软、漂浮或缺口时回到原图复查。

## 方法

每张已定位、去畸变照片转成灰度，等比缩小到最长边不超过 512 像素，再计算中心差分的平均平方梯度能量。这个量与 Tenengrad 一类边缘能量测量有相同的用途：细节、纹理和清晰边缘减少时，分数通常会降低。

只在至少四张已定位照片时计算。提示线是本次照片中位数的 25%，低于该线的视角会显示在质量报告和任务警告中。它只比较同一次采集，既不跨项目比较，也不自动移除训练照片。

低分可能来自大面积纯色墙面、失焦、抖动、过曝、欠曝或重压缩。相反，分数正常也不能证明位姿、视差、遮挡和表面覆盖充足。因此页面只建议检查原图并按实际情况补拍，不能把它读成失焦分类器或模型质量分数。

## 真实照片复核

固定 ETH3D office / pipes 的公开照片、共享内参、3,000 步、512 像素、30 万高斯预算、SH3、种子 42 和每 8 张留出一张的评测模式。新增字段属于位姿快照，两个任务都重新求解 SfM；GPU 串行执行，未同时打开浏览器渲染。

| pipes | 14 / 14 | 0.006142 / 0.001535 | 无 | 10,811 | 18.624418 / 0.75983120 | 6.0273 / 23.2273 / 29.31 s |
| office | 26 / 26 | 0.004133 / 0.001033 | 照片 4、5、6 | 14,611 | 21.261750 / 0.88082280 | 8.6403 / 24.2832 / 33.00 s |

office 的照片 4–6 是大面积低纹理的墙面视角，报告把它们与稀疏轨迹偏低视角并列展示；pipes 没有触发。这说明提示能保守地暴露相对低细节视角，但不证明三张照片都存在运动模糊。两组最终模型均包含完整 SH3、相机与留出渲染；浏览器实际检查了质量报告和 PLY、splat、相机、报告四类下载文件。完整机器可读结果见 [image-detail.json](benchmarks/image-detail.json)。

留出照片仍参与上游 SfM，PSNR / SSIM 仅用于这次同配置任务的完整性检查，不能和不同视图集合、分辨率或旧任务直接作画质差值。新诊断没有关闭对照计时，不能写作性能或画质收益。

## 参考

- NIST 对 [Tenengrad 边缘能量](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=890060)的说明：使用梯度算子估计焦点，但需要结合图片内容解读。
- [BAGS](https://arxiv.org/abs/2403.04926)：讨论真实图像中的不同模糊对 Gaussian Splatting 的影响；本项目未移植该方法，只采用更保守的采集复查提示。
- [3D Gaussian Splatting](https://arxiv.org/abs/2308.04079)：基础表示与训练方法。
