# 工作台布局

目标：在常见的 1280×720、1440×900 桌面窗口里，看到模型、项目状态和重建操作；页面本身不向下拉成长条。

## 设计约定

- 基础色：画布 `#0b111c`，面板 `#131c2b`，边框 `#253248`，主文字 `#e9eff9`，辅助文字 `#8f9eb5`，操作蓝 `#3b82f6`。
- 字体：系统无衬线字体，中文优先 PingFang SC。标题 18–20px，正文 13px，元信息 11px；标题直接说明功能。
- 排列：文字和表单左对齐，数字采用等宽数字。模型是中心，控件靠边放。
- 每种边框都有用途：分隔项目、画布和检查器，不用成堆的独立信息卡。

```text
┌─ Web Scan ─────────────── 项目名 ───────── 帮助 / 本地状态 ┐
│ 项目列表    │                   │ 项目摘要                │
│             │   三维画面        │ 计算模式 / 参数          │
│             │   或采集预览      │ 任务状态                │
│ 新建 / 示例 │                   │ 开始 / 取消 / 下载       │
│             ├───────────────────┤                         │
│             │ 照片缩略条 / 全部 │ 日志 / 详细报告          │
└─────────────┴───────────────────┴─────────────────────────┘
```

照片全集、单张大图、日志、帮助和更多设置使用独立对话框。项目首页用分页网格，避免项目越多页面越长。窄屏保留模型和底部操作，侧栏和设置通过按钮打开。

工作台优先展示模型和常用操作。教程、日志和详细信息在独立面板中打开，蓝色用于操作、选中项和进度。


## 采集详情

未完成重建的项目改为居中的采集页：返回与标题、照片计数、完成按钮、拍摄 / 导入区域、少量缩略图。设置单独打开，不占据采集画面。已完成项目保留上述模型工作台。颜色与字体沿用本项目，交互顺序参考 Aholo Reality 的采集详情。
