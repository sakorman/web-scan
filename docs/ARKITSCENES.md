# ARKitScenes 的设备轨迹、深度与完整 SH3 模型

使用 Apple ARKitScenes 官方训练样本 47333462。从覆盖 59.49 秒的轨迹等间隔取 96 个时间戳，每个时间戳取最近的同步彩照、深度及逐帧内参，最大时间差 0.50 毫秒。从同一批 256×192 照片出发，纯照片 COLMAP 的最大模型仅包含 20 个视角；使用采集附带的相机轨迹与深度可以训练全部 96 个视角对应的场景。设备采集和上游轨迹生成时间没有计入本机处理时间。[Gilad Baruch 等，ARKitScenes](https://arxiv.org/abs/2111.08897) · [官方原始数据格式](https://github.com/apple/ARKitScenes/blob/main/DATA.md) · [数据许可](https://github.com/apple/ARKitScenes/blob/main/LICENSE)

## 训练与评分

相机使用每帧的 PINHOLE 内参，沿用官方轨迹的世界到相机方向。深度单位从毫米换算为米，只用 84 张训练照片的有效深度生成 16,118 个带颜色初始点。12 张留出照片的颜色和深度均未用于高斯训练和点初始化，采集附带的轨迹可能已经使用过这些视角。每个原始 JPEG 都保持原有编码。Brush 0.3.0 Metal 使用种子 42、1000 步、15 万高斯上限，训练分辨率上限 512，留出渲染实际为 256×192。[相机坐标约定参考实现](https://github.com/apple/ARKitScenes/blob/main/threedod/benchmark_scripts/utils/tenFpsDataLoader.py) · [逐帧评分与失败视角](benchmarks/arkit-47333462.json)

| 观测及方法 | 覆盖 | 本机计时 | 结果 |
| --- | ---: | ---: | --- |
| 纯照片，全配对、共享 RADIAL | 20/96 | 稀疏阶段 1.66 秒 | 低于任务的最低覆盖率，未训练 |
| 纯照片，全配对、自动 SIMPLE_RADIAL | 20/96 | 稀疏阶段 1.90 秒 | 最大注册模型未达到最低覆盖率 |
| 已有轨迹、内参和配准深度 | 96/96 | 本地归档到模型及下载校验 4.83 秒 | 30,716 个高斯，完整 SH3 PLY 7,250,526 字节 |

全部数据已在本机。新的独立任务从本地归档生成输入用 0.33 秒，导入用 0.28 秒，工作进程读取冻结相机和点用 0.086 秒，训练与导出用 3.72 秒，端到端包含排队、进程启动、状态轮询和产物检查。两种 COLMAP 配置没有完整模型可作画质或端到端加速比对照。数据集没有在本实验中提供独立的轨迹精度真值。实际留出渲染和相同尺寸原照片逐像素评分为 **18.533 dB / 0.70923 SSIM**。海报边缘和部分文字可辨，窗边植物、暖气片和柜门细节明显模糊。截图在本地实验目录 `heldout.jpg`，显示第 0、48、88 帧。此次检查固定拍摄视角。

## 小尺寸 JPEG 的训练兼容性

同一份采集最初通过导入校验，但 Brush 读取照片时报告提前到达文件末尾。把位姿模型从标准文本转换成二进制后仍出现相同错误。96 张 JPEG 中有 16 张长度小于该版读取器的首个缓冲区；照片可正常解码。现在训练时仅对这些照片创建临时副本，在 JPEG 元数据区增加注释段，像素、尺寸和原有 Exif 均保留。16 张共增加 28,247 字节。原始文件和冻结副本继续按原摘要校验。两次实拍训练均完成；第一次重试报告的 Brush PSNR 为 18.64 dB，独立验收为 18.53 dB。首次重试复用已导入的场景，未用于完整流程计时。[Brush 0.3.0 图像读取实现](https://github.com/ArthurBrussee/brush/blob/v0.3.0/crates/brush-dataset/src/scene.rs)

## 复现

将官方的 `lowres_wide.traj`、`lowres_wide.zip`、`lowres_wide_intrinsics.zip` 和 `lowres_depth.zip` 放入同一目录。以下命令创建一份新的训练输入，并将它导入工作台。源数据和模型均保存在本机。该采样脚本为每八帧留出一帧的深度初始化准备，未估计新的采集轨迹。

```sh
.venv/bin/python -m scripts.prepare_arkitscenes \
  --assets .samples/archives/arkitscenes-47333462 \
  --out .data/benchmarks/arkit-reproduction/posed
.venv/bin/python -m webscan.import_poses .data/benchmarks/arkit-reproduction/posed \
  --name "ARKitScenes 47333462"
```

本次只检验一段低分辨率室内采集。下一步固定相机与留出视角，单独检查缺少实测深度时的初始几何。[已知位姿导入命令与 ETH3D 基准](POSED-IMPORT.md)

## 固定位姿，去掉输入深度

同一批 96 张 RGB 图片逐张 SHA-256 一致。保留设备内外参，三角化分支只读取轨迹、彩照和内参三个文件。用 84 张训练图匹配和初始化，12 张留出照片专用于训练后的评分。OpenCV SIFT 每张最多 900 个特征，按训练序列与向前第 2、1、4 张图分别尝试配对，使用 L2 最近邻比例 0.75。两个投影矩阵固定，奇异值分解求三角点。两侧深度需在 0.25–5 米内，夹角至少 1.5°，两侧各自重投影误差最多 1.5 像素，同一源特征只保留第一次通过的配对。198 对有候选匹配，准备 2,913 个三角点用 0.50 秒。[COLMAP 已知位姿三角化说明](https://colmap.github.io/faq.html#reconstruct-sparse-dense-model-from-known-camera-poses)

对照从原来的 16,118 个训练深度点中，按原序等间隔选 2,913 个。两组使用同一组相机、相同照片、1000 步及原始 256×192 画幅。每种方法训练一次。

| 初始化 | 实际高斯 / PLY 字节 | 训练与导出（秒） | 从导入到完成（秒） | 同视角 PSNR / SSIM |
| --- | ---: | ---: | ---: | ---: |
| 训练 RGB 三角化 | 5,606 / 1,324,565 | 2.96 | 3.61 | 16.270 / 0.63999 |
| 同点数传感器深度 | 5,610 / 1,325,509 | 2.97 | 3.85 | 17.624 / 0.65348 |

只用彩照和已有轨迹可生成模型，但在相同初始点数下仍低 1.35 dB。点的空间分布、跨帧对应和初始颜色来源可能不同，只凭本组无法归因。继续保留深度初始化为有深度采集的默认入口。无深度方案留作实验，后续检查低纹理区域覆盖和跨三帧的轨迹验证。复现采样使用前述序列、时间与划分，保存的本地实验目录为 `.data/benchmarks/arkit-triangulation-20261127`，其中 `triangle.py` 和 `heldout.jpg` 分别为运行脚本与同视角图。[两组逐帧数据](benchmarks/arkit-triangulation.json)

## 固定特征位置后替换深度

前一组等点数实验证明，训练深度网格的留出 PSNR 超过稀疏三角化。为检查其中有多少来自距离估计，这次固定 2,913 个点的 ID、相机、源像素投影、颜色和轨迹观测。每个点只沿原来的源相机射线移动，替换为该训练帧在同像素测到的轴向深度。选取 0.25–5 米内的连续有效表面，3×3 邻域中最大深度差相对中心不超过 5 厘米。共从 68 张训练深度图校正 2,865 个点，其余 48 个沿用原坐标。三维位移中位数 2.47 厘米，第 90 百分位 9.98 厘米，源照片上的最大投影变化小于十亿分之一像素。准备耗时 0.169 秒。[射线对照程序](benchmarks/arkit-fixed-rays.py) · [ARKitScenes 原始深度格式](https://github.com/apple/ARKitScenes/blob/main/DATA.md)

仍使用 96 张已定位照片，84 张训练、12 张留出，无失败视角。相机轨迹、原图及匹配已就绪，上游 SfM 耗时未计入本轮。四次独立 Brush 0.3 Metal 训练依次运行两视图 A、实测深度 A、实测深度 B、两视图 B。每次 1000 步，种子 42，高斯上限 15 万。原图和渲染的评分画幅均为 256×192。

| 顺序与初始化 | 实际高斯 / PLY 字节 | 训练导出 / 导入至完成（秒） | 留出 PSNR / SSIM |
| --- | ---: | ---: | ---: |
| 1 · 三角化 A | 5,604 / 1,324,093 | 3.15 / 3.88 | 15.947 / 0.63651 |
| 2 · 实测深度 A | 5,567 / 1,315,361 | 2.95 / 3.81 | 15.799 / 0.63131 |
| 3 · 实测深度 B | 5,599 / 1,322,913 | 3.00 / 3.57 | 16.047 / 0.63571 |
| 4 · 三角化 B | 5,599 / 1,322,913 | 2.89 / 3.31 | 16.243 / 0.63913 |

两组配对的 PSNR 分别下降 0.148、0.196 dB，SSIM 也均下降。同一设置重跑的 PSNR 相差 0.25–0.30 dB。这个场景上，只改距离没有重现此前按网格分布实测深度点的收益。第 48 帧窗台的盆栽与暖气片仍模糊，第 0 帧海报标题仍难辨。固定视角截图保存在本地实验目录 `.data/benchmarks/arkit-fixed-rays-20261127/heldout.jpg`。这项实验需要有配准深度的实拍采集，两组 ETH3D 在同一轮次的三视图实验中另行评分。下一步固定每帧点数和深度来源，比较源像素分布。[四组逐帧评分](benchmarks/arkit-fixed-rays.json) · [ETH3D 三视图对照](THIRD-VIEW.md)

## 相同点数与深度来源，改变源像素分布

固定同一场景、设备相机和 68 张提供初始点的训练照片。每帧的预算来自该帧具有稳定深度的特征像素，去除重复位置后合计 2,612 个。两种方法在相同的有效深度范围内，使用相同的逐帧预算、传感器深度、成像公式和原照片取色。第一种取原特征所在的整数像素。第二种从靠近图像中心的有效像素开始，每次选离已选像素最远的位置。两组点均只有一项源帧观测。逐帧统计有点落入的 8×6 网格数，68 帧合计从 819 格增至 1,815 格。几何和输入准备从 0.16 秒增至 0.78 秒。[复现程序](benchmarks/arkit-seed-coverage.py) · [原始数据与方法](https://arxiv.org/abs/2111.08897)

| 训练顺序与取点 | 最终高斯 / SH3 PLY 字节 | 训练导出 / 导入至完成（秒） | 留出 PSNR / SSIM |
| --- | ---: | ---: | ---: |
| 1 · 特征 A | 5,023 / 1,186,977 | 2.95 / 3.82 | 15.856 / 0.63614 |
| 2 · 空间 A | 5,053 / 1,194,057 | 2.95 / 3.81 | 17.074 / 0.64758 |
| 3 · 空间 B | 5,059 / 1,195,473 | 2.90 / 3.54 | 17.013 / 0.64637 |
| 4 · 特征 B | 5,044 / 1,191,933 | 2.90 / 3.55 | 16.021 / 0.63663 |

两次配对的平均 PSNR 分别增加 1.218 和 0.992 dB，各有 10/12 张留出照片改善。SSIM 分别增加 0.01143 和 0.00974。96 张输入均有位姿，无失败视角，84 张训练，12 张在 256×192 原始画幅评分。沿用上节的训练参数与热缓存，未重新求姿。在这一场景和点数预算下，深度点的像素分布影响最终画质。每个新位置也会采到不同表面的深度与颜色。海报小字、暖气片和窗台植物在两组里仍然模糊，气球所在的彩色区域在空间采样下更可见。同视角截图保存在本地实验目录 `.data/benchmarks/arkit-seed-coverage-20261127/heldout.jpg`。[配置、逐帧点数与全部评分](benchmarks/arkit-seed-coverage.json)

当前设备深度导入本来就按规则网格取点，本实验只与特征位置取深度作对照。下一步使用相同预算直接检验规则网格与最远点采样的时间和画质。本结果限于已有设备轨迹与配准深度的一段室内采集。

## 在 16 像素网格上选择相同数量的深度点

将最远点采样的候选限制到原有深度初始化的 16 像素网格，起点为 (8, 8)。仍按同一个 3×3 邻域排除深度跳变，保留每帧相同预算。68 个源视角每帧有 166–192 个有效网格候选，预算为 1–163 个点，合计 2,612 个。全像素和网格候选分别覆盖 1,815 和 1,855 个逐帧统计的 8×6 图格。离线程序的 `--lattice` 参数可复现网格组，复现的相机和点文件与训练输入逐字节相同。[复现程序](benchmarks/arkit-seed-coverage.py)

在内存中预先准备所有有效掩码，两种方法各预热一次，再交替计时六轮。68 帧纯 CPU 选点中位耗时从 657.2 毫秒降到 13.2 毫秒。独立准备训练输入耗时分别为 0.78 秒（前一轮全像素）和 0.13 秒（本轮网格）。四次串行训练均复用已有相机，96 帧全部注册，84 张训练、12 张留出。Brush 步数、分辨率、种子及评分方法沿用上节。[六轮计时、模型大小与逐张评分](benchmarks/arkit-grid-budget.json)

| 初始化 | 实际高斯 / SH3 PLY 字节 | 训练与导出 / 导入至完成（秒） | 留出 PSNR / SSIM |
| --- | ---: | ---: | ---: |
| 全像素 A | 5,066 / 1,197,125 | 3.13 / 3.82 | 17.353 / 0.65002 |
| 网格 A | 5,067 / 1,197,361 | 3.35 / 4.33 | 17.198 / 0.64975 |
| 网格 B | 5,058 / 1,195,237 | 3.25 / 3.82 | 17.004 / 0.64935 |
| 全像素 B | 5,063 / 1,196,417 | 3.25 / 4.09 | 17.088 / 0.64888 |

网格方案两次配对 PSNR 低 0.155 和 0.084 dB。两种初始化各自重跑的波动为 0.19–0.26 dB。采样阶段节省约 0.64 秒，导入后的耗时没有出现一致改善。本轮只测试一段已知轨迹和配准深度的采集。生产入口原本按网格直接取点，以上计时专指限额最远点采样。使用更大预算之前，需要验证扩大初始点数对最终模型大小和画质的影响。
