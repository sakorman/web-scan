# 原地旋转提示

2026-10-29。已有的“拍摄位置”诊断会计算已定位相机的最近邻间隔；当所有相机中心重合时，它会保留 `coincident_camera_centers` 原因，却没有显示在质量报告或任务警告中。本次把这个已有判定接入界面与报告，明确提示仅在原地转动镜头没有三维深度所需的平移视差。它不改变 COLMAP、训练、照片、模型或历史任务。

## 判定与呈现

1. 仍从归一化后的已定位外参恢复相机中心；至少 3 张已定位照片才检查。
2. 所有最近邻中心距离都低于数值精度时，位置诊断保留 `coincident_camera_centers`；不使用文件顺序或照片方向。
3. 质量报告的“拍摄位置”改为明确的原地旋转说明，任务警告同步提示围绕目标做小幅横移后补拍。

这是一条明确的退化采集提示，不是模型质量分数。相机中心不重合也不能保证足够的基线、视场重叠、纹理、无遮挡或完整表面；单平面目标的最佳拍摄方式也可能不同。COLMAP 的采集指导同样建议从不同位置拍摄，不要只在同一位置旋转相机。

## 回归与真实照片复测

矩阵回归覆盖三张相机中心重合时的 `coincident_camera_centers` 结果，及少于三张相机不作判断。位置与朝向诊断保持独立：同一位置旋转时，即使光轴分散，位置提示仍会指出缺少平移视差。

Apple Silicon macOS、PyCOLMAP 3.13.0、Brush 0.3.0。使用 ETH3D 公开室内照片、共享内参、3,000 步、512 像素长边、30 万高斯预算、SH3、种子 42 和每 8 张留出 1 张。GPU 串行运行；两组均复用上轮已验证的 SfM 缓存，单独列出缓存恢复时间，不把它与冷启动混为一谈。留出照片参与过上游 SfM，不是独立端到端评测。

## 限制与下一步

- 纯照片 SfM 在严格原地旋转时通常会退化或无法形成有效三维模型；该提示只处理仍返回重合外参的情况，不能替代失败任务的排查。
- 手机 IMU、ARKit/ARCore、LiDAR 或外部轨迹提供的平移尺度需要独立验证，不能与这个纯视觉、归一化坐标判定混用。
- 下一步以有已知原地旋转段和真实横移段的合法采集，核验提示的命中率、误报率及其与稀疏轨迹支撑的关系。
