# 拍摄位置间隔诊断

2026-10-28。稀疏轨迹支撑能发现一张照片和三维点关联偏少，却不能反映一组已定位相机在空间中的位置是否突然跳开。本次在同一份 COLMAP 位姿上补充最近邻相机间隔提示，用于指出应优先复查重叠的拍摄位置；不修改相机求解、训练器、原始照片或历史模型。

## 计算方式

1. 从已定位照片的外参矩阵恢复相机中心。坐标使用已有的场景归一化，因此只在当前任务内部有相对意义。
2. 对每个相机中心计算到其它已定位相机中心的最近距离，取所有最近距离的中位数 `m`。
3. 相对提示线为 `2.5 × m`；严格高于该线的照片列为“位置间隔偏大”。少于三张照片或所有相机中心重合时不下结论。

照片输入可以来自相册、文件选择或视频抽帧，顺序未必就是拍摄路径，所以算法不使用文件序号推断前后关系。较大间隔可能是合理的广角视角、场景尺度或正常绕拍，也可能是缺少过渡照片；它不是画质分数、不是尺度测量，也不能证明所有表面拍全。

质量报告新增“拍摄位置”区：显示任务内中位数和相对提示线，最多列出六张相对孤立的已定位照片。它与稀疏轨迹支撑分开显示；前者看相机位置密度，后者看点轨迹关联，二者不应相互替代。

## 取舍与下一步

- 归一化尺度会随场景变化，数值不能跨项目比较；提示线只和本任务自己的相机集合比较。
- 只用相机中心，未计入朝向、视场角、遮挡、纹理和真实可见重叠；大间隔不必然是坏照片，小间隔也不保证有足够视差。
- 下一步在连续手机采集、混合焦段和已知缺口的合法公开场景上核对提示是否确实对应空洞或漂浮区域；在有 IMU / 位姿来源时，应单独验证时间和传感器尺度，而不是混入纯照片结论。
